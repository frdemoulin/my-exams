# UE14 EB01 — Revue documentaire préalable

**Objet :** synthèse des sources utilisées pour cadrer EB01.  
**Statut :** revue préalable à la rédaction — le seed livré est ensuite autonome.

## 1. Référentiel actuel UE14

La cartographie actuelle du Tutorat Santé de Reims confirme les blocs pédagogiques à couvrir :

- Chimie : 1.1 à 1.4 puis 2.1 à 2.7 ;
- Biochimie : glucides, lipides, protides, enzymologie ;
- Biologie cellulaire : 9 chapitres, d’Organisation de la cellule au Cycle cellulaire.

My Exams ajoute en Chimie un chapitre interne transversal de nomenclature organique, utilisé ici uniquement à l’intérieur de l’EC Chimie.

## 2. Séparation des EC

L’annale officielle UE1 Reims 2015–2016 sépare explicitement les blocs :

- Q1–40 : EC Chimie ;
- Q41–80 : EC Biochimie ;
- Q81–100 : troisième EC.

Conséquence retenue pour EB01 :

> aucune question inter-EC ; la transversalité est exclusivement intra-EC.

## 3. Annales officielles — enseignements retenus

Les annales historiques montrent l’intérêt de :

- distracteurs courts fondés sur une confusion précise ;
- structures chimiques à interpréter ;
- questions de nomenclature et de réactivité ;
- pièges de position, signe, famille moléculaire ou enzyme ;
- enchaînements sur lipides, phospholipases et sphingolipidoses.

Les idées de pièges et erreurs classiques sont réutilisées lorsque pertinentes, sans reprise textuelle d’une question complète.

## 4. Tutorat / concours blancs

Les corrections du CCB montrent explicitement l’utilisation de petits pièges destinés à vérifier la précision de lecture.

Principe retenu :

- piège plausible ;
- erreur classique réelle ;
- aucune ambiguïté ;
- correction expliquant précisément le piège.

## 5. Prépas — Médical Reims / Cours Laplace

Les supports disponibles montrent notamment :

- questions partageant une structure ou des données communes ;
- raisonnement en plusieurs étapes ;
- calculs et interprétations de données ;
- distracteurs issus d’une erreur intermédiaire.

EB01 conserve ce principe avec quatre groupes liés naturels seulement.

## 6. Points scientifiques particulièrement vérifiés

### Chimie

- nucléides : A/Z/N distingués ;
- électronégativité ≠ affinité électronique ;
- liaison polarisée ≠ molécule nécessairement polaire ;
- σ/π et hybridations sp, sp², sp³ ;
- digonale/linéaire, pas « diagonale » ;
- R/S indépendant du signe du pouvoir rotatoire ;
- carbonyle électrophile et addition d’un organomagnésien ;
- reconnaissance ester / amide / thioester / thiol.

### Biochimie

- D/L indépendant du pouvoir rotatoire ;
- glucose/galactose : épimérie C4 ;
- nomenclature Δ et n/ω des acides gras ;
- PLA2 : position sn-2 ;
- eicosanoïdes : COX vs lipoxygénases ;
- céramide = sphingosine + acide gras par liaison amide ;
- Tay-Sachs = hexosaminidase A / GM2 ;
- Fabry = α-galactosidase A ;
- Gaucher = glucocérébrosidase/β-glucosidase acide ;
- liste des huit AA indispensables telle qu’enseignée dans le support actuel ;
- Km ≠ Kd ;
- Lineweaver–Burk ;
- effets idéalisés des inhibitions compétitive, non compétitive et incompétitive.

### Biologie cellulaire

- SGLT : transport actif secondaire ;
- actine / microtubules / filaments intermédiaires ;
- COPII RE→Golgi, COPI retour/intra-Golgi, clathrine ;
- N-glycosylation débutant dans le RE, O-glycosylation principalement golgienne ;
- M6P et adressage lysosomal ;
- peroxysome : une membrane, pas de génome, hors SEM ;
- PTS1/PEX5 ;
- β-oxydation peroxysomale des acides gras à très longue chaîne ;
- mitochondrie : double membrane, génome propre, chaîne respiratoire ;
- complexe II : pas de pompage direct de protons ;
- lamine ≠ laminine ;
- G2 = 2n/4C.

## 7. Originalité

Les 315 questions des colles et les banques de quiz existantes ont servi à éviter la quasi-duplication.

L’originalité exigée porte sur :

- l’énoncé concret ;
- les données ;
- la construction ;
- l’enchaînement des items.

Elle ne porte pas sur les erreurs classiques elles-mêmes : un piège fondamental peut être réutilisé dans plusieurs évaluations.

## 8. Conclusion

EB01 a été construit comme un examen autonome de 100 questions, informé par les pratiques d’évaluation de Reims et les contenus actuels, sans dépendre d’une source externe lors de la passation.
