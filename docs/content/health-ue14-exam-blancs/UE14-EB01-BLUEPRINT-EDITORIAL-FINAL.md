## 2. Revue documentaire préalable — conclusions utiles

- La cartographie actuelle UE14 confirme **11 chapitres de Chimie** (1.1→1.4 puis 2.1→2.7), auxquels My Exams ajoute le chapitre transversal interne **2.8 Nomenclature organique**.
- La Biochimie couvre **15 chapitres internes My Exams** : glucides, lipides, protides et enzymologie ; les eicosanoïdes sont séparés en interne.
- La Biologie cellulaire couvre **9 chapitres** : Organisation → Membrane → Cytosquelette → SEM 1 → SEM 2 → Peroxysome → Mitochondrie → Noyau → Cycle cellulaire.
- Les annales officielles historiques de Reims confirment la logique d’une **épreuve longue de 100 questions / 2 h 30**, mais leur ancien découpage PACES ne doit pas dicter le blueprint actuel.
- Les annales et concours blancs montrent des questions fondées sur des **structures**, des **confusions précises**, des **listes piégeuses**, des **erreurs de position**, des **erreurs de signe/direction** et des **mécanismes de réaction**. Ces idées et pièges classiques sont réutilisables.
- Les supports actuels autorisent des mises en situation médicales scientifiquement pertinentes : sphingolipidoses, anomalies peroxysomales, défauts d’adressage lysosomal, etc., à condition que la clinique ne soit jamais une connaissance préalable nécessaire.
- Les banques My Exams déjà validées servent de contrôle de couverture et de non-quasi-duplication ; elles ne servent pas à recycler des questions.

## 7. Transversalité prévue — uniquement à l’intérieur d’un même EC

Les examens de référence séparent nettement les EC. **EB01 respecte donc strictement cette logique : aucune question ne doit exiger de croiser des connaissances appartenant à deux EC différents.**

La transversalité recherchée est exclusivement **intra-EC**, c’est-à-dire entre plusieurs chapitres d’un même EC :

- **Chimie** : atomistique + liaisons ; stéréochimie + nomenclature ; fonctions organiques + réactivité ; nomenclature + fonctions multiples.
- **Biochimie** : glucides entre structure et liaisons ; lipides entre structure, nomenclature et enzymes ; protéines entre structure et fonction ; enzymologie entre mécanisme, cinétique et régulation.
- **Biologie cellulaire** : membrane + transport ; cytosquelette + moteurs ; RER/Golgi/lysosome + trafic ; peroxysome + adressage + fonctions ; mitochondrie + chaîne respiratoire ; noyau + cycle cellulaire.

Une question peut mobiliser plusieurs chapitres **du même EC**, mais elle reste entièrement résoluble à partir des contenus de cet EC.

Même lorsqu’une notion existe aussi dans un autre EC (ex. actine, lipides membranaires, β-oxydation), la question doit être rédigée uniquement selon l’angle et les connaissances explicitement enseignés dans l’EC auquel elle appartient.

Le Theme mapping doit suivre la même logique : Theme principal, et éventuellement second Theme, **dans le périmètre du même EC**.

## 8. Pièges classiques réservés pour EB01

Leur réutilisation depuis annales/tutorat/prépas est autorisée. La rédaction finale, elle, doit rester autonome.

- A/Z/N ; noyau vs atome ; proton vs électron.
- σ vs π ; symétrie axiale ; hybridation `sp/sp²/sp³` ; confusion lexicale scientifique plausible.
- R/S vs signe du pouvoir rotatoire ; E/Z vs R/S.
- Markovnikov ; alcool I/II/III ; nucléophile vs électrophile.
- thiol vs thioester ; ester vs amide ; aldéhyde vs alcool (`RCHO` vs `RCOH`).
- D/L vs +/− ; épimère vs énantiomère ; α/β et position de liaison osidique.
- série n/ω vs positions Δ ; PLA1/PLA2/PLC/PLD.
- Km vs Kd ; Vmax/Km/v0/[S] ; inhibition compétitive/non-compétitive.
- glissement actine/myosine vs raccourcissement.
- COPI/COPII/clathrine ; RE vs Golgi ; N- vs O-glycosylation.
- peroxysome vs mitochondrie vs lysosome.
- complexe II mitochondrial : **pas de pompage de protons**.
- lamine vs laminine.
- G2 : **2n/4C**, pas 4n/4C.

## 11. Règles de rédaction du seed EB01

- Les **100 questions sont rédigées comme un seul corpus éditorial définitif**.
- Chaque question fermée comporte **5 items A–E** lorsque le format le prévoit.
- Chaque distracteur doit correspondre à une erreur plausible identifiable.
- Chaque item reçoit une explication individualisée ; aucune correction `Vrai.` / `Faux.` isolée.
- L’explication globale apporte un mécanisme, une méthode ou une synthèse ; elle ne répète pas simplement les items.
- Toute question calculatoire est recalculée indépendamment avant livraison.
- QROC : réponse canonique + variantes acceptables définies explicitement.
- QRPL : 10 propositions / sélection imposée conforme au moteur existant.
- QZONE : asset, cible, coordonnées et tolérance définitifs avant livraison.
- Theme mapping éditorial décidé question par question ; **aucun auto-nearest-map**.
- **Aucune question inter-EC** : Chimie, Biochimie et Biologie cellulaire restent des blocs pédagogiques distincts ; une question peut être transversale uniquement entre chapitres d’un même EC.
- Conformité TeX/KaTeX appliquée **pendant la rédaction**, pas dans une passe ultérieure.
- Aucune reprise quasi textuelle d’une annale/prépa/colle ; les idées, pièges et erreurs classiques sont réutilisables.

## 12. Contrôle anti-répétition pour la série d’EB

À la clôture d’EB01, produire un registre qui mémorise au minimum :
- stableId ;
- Theme(s) ;
- concept précis ;
- structure/molécule/exemple utilisé ;
- groupe lié éventuel ;
- mise en situation éventuelle ;
- QZONE/asset ;
- piège principal.

Pour EB02+, ce registre interdit la quasi-duplication d’une question, **mais n’interdit jamais de réutiliser un piège classique ou une erreur-type**.
