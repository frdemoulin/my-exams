# UE14 EB02 — Revue documentaire préalable et arbitrages scientifiques

**Statut : revue éditoriale préalable à la livraison du seed définitif.**

## 1. Hiérarchie appliquée

EB02 suit le cadrage canonique `docs/content/health-ue14-exam-blanc-authoring.md` :

1. contenus UE14 actuels et cadrages scientifiques déjà validés ;
2. annales officielles historiques de Reims pour la culture d’examen ;
3. tutorat / concours blancs ;
4. prépas et supports historiques pour les idées de pièges et de raisonnement ;
5. EB01 et les 315 questions de colles comme registre de non-quasi-duplication.

Une source historique ou une correction de tutorat n’est jamais utilisée comme autorité lorsqu’un audit scientifique plus récent du projet a déjà arbitré le point.

## 2. Chimie

Points particulièrement contrôlés pour EB02 :

- nucléides, ions et configurations électroniques ;
- tendances périodiques et électronégativité ;
- polarité de liaison versus moment dipolaire moléculaire ;
- liaisons sigma/pi, hybridations `sp`, `sp²`, `sp³` ;
- nitriles et nomenclature ;
- isomérie de constitution, E/Z, R/S et excès énantiomérique ;
- oxydation des alcènes et alcools ;
- substitutions nucléophiles SN1/SN2 ;
- fonctions ester / amide / thioester ;
- carbonyle + amine primaire ;
- acides carboxyliques et nomenclature polyfonctionnelle.

Le mini-dossier Q18–Q20 emploie le 2-bromobutane pour tester le mécanisme SN2 sous un angle différent d’EB01.

## 3. Biochimie

Points particulièrement contrôlés :

- glucides : anomérie, épimérie, liaison du lactose ;
- lipides : séries omega/Delta, eicosanoïdes, phospholipases, sphingolipides, stérides ;
- acides aminés et protéines : ionisation, chaînes latérales, liaison peptidique, structure, immunoglobulines, myosine ;
- transporteurs ABC / P-glycoprotéine ;
- enzymologie : Michaelis–Menten, activité spécifique, inhibitions réversibles, allostérie.

Arbitrages scientifiques maintenus :

- `Km` n’est pas assimilé à `Kd` ;
- inhibition compétitive pure : `Km` apparent augmente, `Vmax` inchangée ;
- inhibition incompétitive pure : `Km` et `Vmax` diminuent dans la même proportion ;
- inhibition non compétitive pure : `Km` inchangé, `Vmax` diminuée.

Le mini-dossier Q54–Q56 utilise un jeu numérique propre à EB02 et une nouvelle QZONE sur le plateau commun de `Vmax`.

## 4. Biologie cellulaire

Points particulièrement contrôlés :

- membrane et transports ;
- cytosquelette, centrosome et moteurs ;
- endocytose médiée par récepteur ;
- COPI / COPII / clathrine, Rab / SNARE ;
- N-glycosylation, lysosome, autophagie ;
- PTS1 / PEX5 et fonctions peroxysomales ;
- mitochondrie, chaîne respiratoire, complexe IV, TOM/TIM ;
- noyau, NLS, lamina ;
- cycle cellulaire, p53/p21, Rb/E2F, kinétochores et fuseau.

### Arbitrages récents conservés

Pour l’endocytose LDL, l’audit scientifique actuel du projet prévaut sur certaines formulations anciennes du support de tutorat :

- la dynamine est traitée comme une grande GTPase de scission ;
- l’endosome précoce est déjà acidifié ;
- le récepteur LDL recycle majoritairement vers la membrane plasmique tandis que le LDL poursuit vers la voie endolysosomale.

Pour le cycle cellulaire :

- la réponse aiguë aux dommages de l’ADN en G1 est formulée principalement via p53–p21 ;
- Rb/E2F relie l’activité cycline-CDK à l’entrée en phase S ;
- un kinétochore non correctement attaché entretient le checkpoint du fuseau ;
- G2 reste `2n/4C`.

## 5. Originalité / anti-répétition

EB01 est utilisé comme contrôle explicite.

- 0 stem EB01 repris à l’identique ;
- nouveaux mini-dossiers ;
- nouveaux supports QZONE ;
- nouveaux jeux de données ;
- nouveaux exemples moléculaires ou cellulaires.

Les formulations génériques propres aux formats (« sélectionnez exactement… », « quelles propositions… ») ne sont pas considérées comme une duplication éditoriale.

Les pièges classiques restent réutilisables : SN1/SN2, R/S versus signe du pouvoir rotatoire, `Km` versus `Kd`, COPI/COPII, N- versus O-glycosylation, lamine versus laminine, etc.

## 6. Conclusion

Le seed EB02 remis à l’intégrateur est autonome, scientifiquement arbitré et éditorialement final. Gemini ne doit compléter ni corriger aucun contenu.
